# Python-quiz-engine-leaderboard

This is a terminal based Python quiz games with multiple types of quizes,scoring system,file storage and leaderboards.

 Features:
 
- Multiple quiz categories (Maths, Spanish, General Knowledge) 
- Score tracking system 
- File-based data storage (scores.txt) 
- Leaderboard system sorted by highest score 
- Input cleaning and validation 
- Error handling for invalid inputs 
- Replayable quiz loop with exit option 

 What I learnt:
 
- Error handling (try/except) 
- defining functions  
- conditional loops  
- Sorting data into leaderboards  
- File storage  
- Data structure 
- Building a simple leaderboard system
